# Fixtures

These fixtures are deterministic inputs for the asset compiler and runtime loader. They are
safe to commit except where noted.

## Layout

- `cars/minimal/car.json`: one body box, four cylinder wheels, and a hand-authored physics
  configuration.
- `cars/mazda-rx7/`: default demo car. CC BY 3.0; see its README for attribution.
- `tracks/minimal/track.json`: ground plane, two walls, start line, a generated gauge-texture
  sign, spawn point, cameras, surfaces, and labeled X/Y/Z axes.
- `tracks/skidpad05/pack.sima`: temporary default demo track. The source archive had no
  license metadata; see its README before redistribution.

## Coordinate contract

- Units: meters, kilograms, seconds, radians.
- Right-handed frame: `+Y` up, `-Z` forward.
- `+X` is right, so the left wheels have negative X positions.
- Front wheels have negative Z positions; rear wheels have positive Z positions.

## Baked packs

The `.sima` files are generated by the asset compiler and checked in for loader tests and
demos. Re-bake them after changing a fixture:

```bash
cargo run -p asset-compiler -- bake car fixtures/cars/minimal
cargo run -p asset-compiler -- bake track fixtures/tracks/minimal
cargo run -p asset-compiler -- bake-glb fixtures/cars/mazda-rx7/mazda-rx7.glb
```

The Skidpad pack is baked from the raw AC mod under `fixtures/real/`:

```bash
cargo run -p asset-compiler -- bake-ac-track fixtures/real/tracks/skidpad05 \
  fixtures/tracks/skidpad05/pack.sima
```

## Real assets

Raw mod assets are not committed. Place them under `fixtures/real/` and follow
`docs/manual-asset-testing.md`. The `fixtures/real/` directory is gitignored.
