# Fixtures

These fixtures are synthetic, deterministic inputs for the asset compiler and runtime
loader. They are safe to commit and must not contain third-party game assets.

## Layout

- `cars/minimal/car.json`: one body box, four cylinder wheels, and a hand-authored physics
  configuration.
- `tracks/minimal/track.json`: ground plane, two walls, start line, spawn point, cameras,
  surfaces, and labeled X/Y/Z axes.

## Coordinate contract

- Units: meters, kilograms, seconds, radians.
- Right-handed frame: `+Y` up, `-Z` forward.
- `+X` is right, so the left wheels have negative X positions.
- Front wheels have negative Z positions; rear wheels have positive Z positions.

## Baked packs

The `pack.sima` files are generated by the asset compiler and are checked in for the CP1
loader tests. Re-bake them after changing a fixture:

```bash
cargo run -p asset-compiler -- bake car fixtures/cars/minimal
cargo run -p asset-compiler -- bake track fixtures/tracks/minimal
```

## Real assets

Real mod assets are not committed. Place them under `fixtures/real/` and follow
`docs/manual-asset-testing.md`. The `fixtures/real/` directory is gitignored.
