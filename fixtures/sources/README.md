# Source fixtures

Tracked third-party source assets used to rebuild redistributable demo packs.

These differ from `fixtures/real/`: real mods with unclear or non-redistributable
licenses stay local and ignored, while sources here are committed deliberately
so the corresponding baked packs can be rebuilt and their attribution/source
requirements are met.

- `cars/sc-deckard-conejo/`: Speed Dreams Deckard Conejo plus a Carson donor
  wheel, Free Art License 1.3. See its README and
  `docs/speed-dreams-pipeline.md`.
