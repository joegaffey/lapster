# Race Loop Fixture

A closed demo track that carries a validated race layout. It is the positive
race fixture used by compiler and runtime tests; `fixtures/tracks/minimal` and
the default Skidpad pack remain the "race unavailable" cases.

## Source

- `project.json` is copied from `web/track-ed-src/fixtures/projects/loop.json`.
- `track.json` and `track.glb` were generated from that project by track-ed's
  Lapster GLB exporter. They are generated inputs; edit the track-ed project and
  re-export instead of hand-editing them.
- `track.json` uses `sim-track-glb-v2` with a `race` block at version 1.

## Baked pack

`pack.sima` is generated by the asset compiler and checked in. Re-bake it with:

```bash
cargo run -p asset-compiler -- bake-glb-track fixtures/tracks/race-loop
```

The compiler is deterministic: re-baking the same `track.json` and `track.glb`
produces byte-identical output, so a stale checked-in pack fails the
`crates/track-pack` fixture test.

## Expected shape

- Pack: kind `Track`, id `race-loop`, with a `Race` chunk entrypoint.
- Layout: `main`, closed, forward, 180 centreline points, half-width 5 m.
- Start/finish: section `main`, fraction 0, positioned at `layout.points[0]`.
- Grid: 10 pole-first slots.
- Sectors: 4 equal sectors covering `[0, 1]`.
