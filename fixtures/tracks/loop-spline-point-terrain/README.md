# Loop Spline Point Terrain Fixture

A closed spline-and-terrain track that carries a validated race layout. It
exercises the GLB track importer with a larger visual/collision mesh, terrain,
and a non-zero start/finish fraction.

## Source

- `project.json` is the provided track-ed project (`track-ed/project@5`) named
  "Loop Spline Point Terrain".
- `track.json` and `track.glb` were generated from that project by track-ed's
  Lapster GLB exporter. They are generated inputs; edit the track-ed project and
  re-export instead of hand-editing them.
- `track.json` uses `sim-track-glb-v2` with a `race` block at version 1.

## Baked pack

`pack.sima` is generated by the asset compiler from this directory, so the pack
id matches the fixture directory. Re-bake it with:

```bash
cargo run -p asset-compiler -- bake-glb-track fixtures/tracks/loop-spline-point-terrain
```

The compiler is deterministic: re-baking the same `track.json` and `track.glb`
produces byte-identical output.

## Smoothing

The project uses `samplesPerSegment: 32` for a smoother visual road ribbon.

## Expected shape

- Pack: kind `Track`, id `loop-spline-point-terrain`, with a `Race` chunk
  entrypoint.
- Layout: `section-1`, closed, forward, 471 centreline points, half-width 5 m.
- Start/finish: section `section-1`, fraction ~0.12315, positioned at
  `layout.points[0]`.
- Grid: 8 pole-first slots.
- Sectors: 4 equal sectors covering `[0, 1]`.
